Story Quest

Story Quest is an interactive educational Event Sequencing web application designed for Grade 5 and Grade 6 learners.

The system allows students to practice sequencing stories independently or participate in teacher-guided classroom sessions through a live online classroom.

---

Features

 Offline Mode
- Individual student login
- Persistent progress using LocalStorage
- Event Sequencing gameplay
- Story reading before every activity
- Score tracking
- Resume previous progress on the same device

 Online Classroom
- Teacher creates classroom sessions
- Automatic session code generation
- Students join using session code
- Live participant monitoring
- Live score submission
- Session persistence
- Teacher dashboard

 Audio System
- Synthesized UI sound effects
- Background ambient music
- AI Story Narration (SpeechSynthesis)
- Narration controls
- Global audio settings
- Persistent audio preferences

---

 Built With

- React
- TypeScript
- Vite
- LocalStorage
- Web Audio API
- SpeechSynthesis API
